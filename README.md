# Rhoe Releases

Public release distribution for Rhoe — a lightweight cross-platform customer relationship manager.

## Download

Grab the latest installer from the [Releases page](https://github.com/Stavook/rhoe-releases/releases/latest).

- **Windows**: `Rhoe-Setup-x.x.x.exe`

## Installation

1. Download the `.exe` installer from the latest release
2. If Windows SmartScreen warns about an unrecognized publisher, click **More info** → **Run anyway**
3. Follow the installer prompts

The app installs to your user profile by default — no admin rights required.

## Auto-Updates

Rhoe checks for new releases automatically on startup. When an update is found it downloads in the background and installs the next time you close the app. No action needed.
